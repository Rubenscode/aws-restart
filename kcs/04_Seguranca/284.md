### 4. Qual dos seguintes é um benefício da segmentação de rede? (Selecione DUAS respostas.)
- [x] Ela melhora o desempenho do tráfego de rede.
- [x] Ela expande a faixa de endereço do Protocolo de Internet (IP) de uma rede.
- [x] Permite que os administradores apliquem controles de segurança diferentes a diferentes partes de uma rede.
- [x] Protege uma rede contra ataques de mapeamento de rede.
- [x] Permite a detecção de ameaças com base em assinatura.

> **Observação:** A segmentação de rede tem múltiplos benefícios; as respostas corretas dependem do foco do exame. No reStart, considere **desempenho e aplicação de controles de segurança diferentes** como os principais.
