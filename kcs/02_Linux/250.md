## 250-[LX]-KC - O Shell Bash

#### 1. O que é uma variável?
- [ ] Uma variável é um valor que contém o símbolo &.
- [x] Uma variável é um valor que é substituído pelo script ou comando.
- [ ] Uma variável é exclusivamente um valor que contém um número.
- [ ] Uma variável é exclusivamente um valor que contém uma letra.

***

#### 2. Considere o seguinte comando: `echo $HOME`. Qual parte do comando é a variável?
- [ ] `echo`
- [ ] `$`
- [ ] O comando não tem nenhuma variável
- [x] `HOME`

***

#### 3. Um desenvolvedor está testando um script Bash e quer exibir informações à medida que o script é executado. Qual comando o desenvolvedor deve usar?
- [ ] `run`
- [ ] `env`
- [ ] `chksum`
- [x] `echo`

***

#### 4. Um usuário gostaria de alterar como seus aliases (pseudônimos) são configurados. Qual arquivo o usuário deve mudar para alterar suas configurações?
- [ ] Arquivo host.conf
- [x] Arquivo `.bashrc`
- [ ] Arquivo `.passwd`
- [ ] Arquivo `.profile`

#### 5. Qual variável de ambiente é usada para indicar a localização dos comandos?
