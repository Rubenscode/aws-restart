#### 1. Um desenvolvedor de software está tendo problemas com um processo que é executado em um host Linux. A aplicação não está respondendo. O desenvolvedor decide terminar o processo usando o comando encerrar, que exige o ID do processo (PID). Qual comando o desenvolvedor pode usar para recuperar o PID?
- [x] ps -ef | grep <process_name>
