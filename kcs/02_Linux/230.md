# Linux

## 230-[LX]-KC - Usuários e grupos

#### 1. Quais declarações se aplicam à definição de senhas de usuário? (Selecione DUAS respostas.)
- [ ] As senhas devem ter até oito caracteres.  
- [x] As senhas são definidas com o comando `passwd`.  
- [x] Os usuários podem redefinir suas próprias senhas.  
- [ ] As senhas devem ser inseridas três vezes.  
- [ ] Os caracteres de senha devem ser todos minúsculos.  

***

#### 2. Quais permissões um usuário padrão tem? (Selecione DUAS respostas.)
- [ ] Controlar qualquer serviço  
- [ ] Gerenciar qualquer conta  
- [ ] Gerenciar o Kernel do Linux  
- [x] Controlar todos os arquivos de propriedade do usuário  
- [x] Acessar todos os arquivos para os quais o usuário possui permissões  

***

#### 3. Qual comando concede privilégios administrativos integrais e permite que você alterne para o ambiente do usuário-raiz?
- [ ] `bash`  
- [ ] `useradd`  
- [ ] `sudo`  
- [x] `su`  

***

#### 4. Qual comando permite que você adicione um usuário a um grupo?
- [x] `usermod`  
- [ ] `groupmod`  
- [ ] `sudo`  
- [ ] `groupadd`  

***

#### 5. Qual declaração consiste em uma das melhores práticas para usar a conta raiz?
- [ ] Compartilhe a senha da conta raiz com todos os usuários e monitore o uso da conta por meio de logs.  
- [x] Sempre faça login como um usuário padrão e alterne o usuário para a conta raiz somente quando você precisar elevar as permissões.  
- [ ] Permita que somente usuários de suporte técnico usem a conta raiz.  
- [ ] Use sempre a conta raiz e alterne para uma conta padrão somente quando você testar o sistema.
