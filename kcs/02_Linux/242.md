## 242-[LX]-KC - Gerenciar serviços

#### 1. Qual serviço os clientes da AWS podem usar para monitorar os serviços e recursos da AWS?
- [x] Amazon CloudWatch  
- [ ] Amazon Elastic Compute Cloud (Amazon EC2)  
- [ ] Amazon Simple Notification Service (Amazon SNS)  
- [ ] AWS Control Tower  

***

#### 2. Qual comando lista todos os serviços ativos no Linux?
- [ ] systemctl  
- [ ] systemctl list-units --type=service  
- [x] systemctl list-units --type=service --state=active  
- [ ] systemctl status  

***

#### 3. Qual comando exibe o uso da memória virtual?
- [x] vmstat  
- [ ] free  
- [ ] lshw  
- [ ] fdisk  

***

#### 4. Qual comando exibe o espaço disponível em disco?
- [x] df -h  
- [ ] df -b  
- [ ] df -a -h  
- [ ] df -l  

***

#### 5. Qual comando de desempenho do sistema monitora a memória física disponível?
