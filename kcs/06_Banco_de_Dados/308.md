# Banco de Dados

## 308-[DF]-KC - Amazon RDS 

#### 1. Qual tarefa pode ser realizada automaticamente pelo Amazon RDS ou manualmente por um usuário?
- [ ] Provisionamento de hardware  
- [ ] Configuração do banco de dados  
- [ ] Aplicação de patches no sistema operacional (OS)  
- [x] Backups periódicos  

***

#### 2. Qual opção deve ser especificada primeiro ao criar uma instância de banco de dados (DB) no Amazon RDS?
- [x] Escolher o mecanismo do banco de dados  
- [ ] Escolher o identificador da instância de DB  
- [ ] Escolher uma região da AWS  
- [ ] Conectar à instância de DB  

***

#### 3. Qual tarefa é uma boa prática para alta disponibilidade em uma instância de banco de dados (DB) do Amazon RDS?
- [ ] Replicar os dados seis vezes em três zonas de disponibilidade  
- [ ] Implantar a instância de DB em uma única zona de disponibilidade  
- [ ] Criar uma implantação na mesma região da AWS  
- [x] Implantar a instância de DB em múltiplas zonas de disponibilidade  

***

#### 4. Qual caso de uso representa um motivo para usar o Amazon RDS em vez de outras soluções de banco de dados?
- [ ] Requisições simples GET ou PUT e consultas  
- [ ] Customização de sistema de gerenciamento de banco de dados relacional (RDBMS)  
- [x] Transações complexas ou consultas complexas  
- [ ] Suporte a modelos de dados chave-valor e documento  

***

#### 5. O que é um cluster de banco de dados (DB) do Amazon Aurora?
- [x] Um cluster Aurora consiste em uma ou mais instâncias de DB e um volume de cluster que gerencia os dados dessas instâncias  
- [ ] Um cluster Aurora consiste em uma VPC, sub-rede e grupo de segurança  
- [ ] Um cluster Aurora consiste em uma região da AWS e uma ou duas zonas de disponibilidade  
- [ ] Um cluster Aurora consiste em um endpoint da instância e uma região da AWS
