#### 3. Quais são os principais recursos de um banco de dados NoSQL? (Selecione DUAS respostas.)

- [x] Os bancos de dados NoSQL têm um esquema flexível

- [ ] Os bancos de dados NoSQL podem executar consultas transacionais ou analíticas

#### 5. Qual é o principal benefício do uso de bancos de dados como serviço (DBaaS)?
