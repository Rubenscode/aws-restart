## 305-[DF]-KC - Trabalhar com funções

#### 1. Qual função calcula o número de linhas em uma tabela?
- [ ] `SUM()`  
- [x] `COUNT()`  
- [ ] `MAX()`  
- [ ] `MOD()`  

***

#### 2. Qual declaração SELECT exibe apenas as combinações exclusivas de valores de `district` e `countrycode`?
- [x] `SELECT DISTINCT district, countrycode FROM city;`  
- [ ] `SELECT UNIQUE district, countrycode FROM city;`  
- [ ] `SELECT ORDER BY district, countrycode FROM city;`  
- [ ] `SELECT DIFFERENCE district, countrycode FROM city;`  

***

#### 3. Qual função de string remove o espaço à frente das entradas em uma coluna?
- [x] `LTRIM()`  
- [ ] `MIN()`  
- [ ] `RTRIM()`  
- [ ] `MOD()`  

***

#### 4. Qual função SQL calcula a soma de um conjunto de valores ou a soma de uma expressão?
- [ ] `MAX`  
- [x] `SUM`  
- [ ] `DIFFERENCE`  
- [ ] `COUNT`  

***
