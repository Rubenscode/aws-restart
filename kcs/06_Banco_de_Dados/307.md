#### 2. Qual instrução SQL representa a maneira correta de criar um nome de coluna qualificado?
- [x] `table_name.column_name`  
- [ ] `table_name_column_name.`  
- [ ] `column_name.table_name`  
- [ ] `.table_name_column_name`  

***

#### 3. Um administrador de banco de dados está trabalhando com duas tabelas e quer exibir apenas os valores correspondentes entre elas. Qual cláusula ele deve usar?

- [ ] `OUTER JOIN`  
- [x] `INNER JOIN`  
- [ ] `RIGHT JOIN`  

***

#### 4. Um administrador de banco de dados quer recuperar todas as linhas da primeira tabela e todas as linhas correspondentes da segunda tabela. Qual cláusula ele deve usar?

- [ ] `RIGHT JOIN`  
- [ ] `FULL OUTER JOIN`  
- [x] `LEFT JOIN`  

***
