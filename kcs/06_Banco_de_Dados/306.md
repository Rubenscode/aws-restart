# Bando de Dados

## 306-[DF]-KC - Organizar dados

#### 1. Um gerente de banco de dados às vezes deve agregar dados de linhas diferentes em uma tabela. Eles devem correlacionar os dados em colunas especificadas. Qual cláusula o gerente deve usar?
- [ ] `HAVING`  
- [x] `GROUP BY`  
- [ ] `ORDER BY`  
- [ ] `WHERE`  

***

#### 2. Qual operador pode ser usado para filtrar resultados de consulta depois de aplicar uma cláusula GROUP BY?
- [x] `HAVING`  
- [ ] `ORDER BY`  
- [ ] `BETWEEN`  
- [ ] `WHERE`  

***

#### 3. Um database administrator deve consultar uma coluna que contém datas sequenciais. Ele deseja ver o resultado de sua consulta em ordem decrescente. Qual cláusula o gerente deve usar com GROUP BY para obter resultados em ordem decrescente?
- [ ] `ORDER BY column_name ASC`  
- [x] `ORDER BY column_name DESC`  
- [ ] `ORDER BY column_name HAVING`  
- [ ] `ORDER BY column_name WHERE`  

***

#### 4. Um desenvolvedor de banco de dados escreveu uma consulta que inclui a cláusula `ORDER BY 3`. Que efeito a cláusula ORDER BY tem em consultas SQL?
- [ ] O resultado da consulta excluirá os dados que tenham valor de 3 para a terceira coluna na cláusula SELECT.  
- [ ] O resultado da consulta incluirá apenas os dados que tenham valor de 3 para a terceira coluna na cláusula SELECT.  
- [ ] O resultado da consulta será organizado pela terceira tabela na cláusula FROM.  
- [x] O resultado da consulta será organizado pela **terceira coluna na cláusula SELECT**.  

***

#### 5. Se um desenvolvedor de banco de dados quiser limitar o resultado de uma consulta apenas para os clientes com vendas maiores de 5.000 unidades, que cláusula SQL ele deve usar?
- [ ] `GROUP BY SUM(sales) > 5000`  
- [ ] `WHERE SUM(sales) > 5000`  
- [x] `HAVING SUM(sales) > 5000`  
- [ ] `HAVING sales < 5000`
